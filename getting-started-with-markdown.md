# Getting Started with Markdown

This guide will help you get started with Markdown and understand its basic syntax.
## What is Markdown?
Markdown is a lightweight markup language used to format text using simple symbols.

Instead of using the traditional bold and italic formatting, Markdown allows you to use special symbols to format text. 

Markdown is used for technical writing and documentation on platforms such as GitHub, WordPress, and help centers.

## Why use Markdown?
Markdown is popular because it is
- Easy to learn and use.
- Easy to read and clean.
- Supported by many tools and platforms like GitHub.
- Fast for writing and editing.
- Allows you to focus on the content instead of formatting.

## Common uses of Markdown
Markdown is commonly used for:
- Writing documentation.
- Formatting notes.
- Creating articles for help centers.
- Writing blog posts.
- Creating README files.

## Basic Markdown syntax
To get started with Markdown, you only need to learn a few basic elements:
### Headings 
 To create headings: 
- # Heading = # Heading 1.
- ## Heading = ## Heading 2.
- ### Heading = ### Heading 3.

### Bold and Italic
- ** text ** = **bold.**
- * text * = *Italic.*

### Blockquote 
To create a blockquote:
Put this( > ) + yor text
### Lists
Unordered list:
- Item 1
- Item 2
- Item 3
### Links
To add a link, use the following syntax:	

[Google](https://www.google.com)

To add an image, use the following format:

![alt text](image link)

### Inline code 
To add inline code, use this:
`code`

### Tables 
To add tables, use the following :
Put your text between this ( | ) like

| Name  | Age | Weight |
|-------|-----|--------|
| Farah | 26  | 50kg   |

## Where can you use Markdown?
You can use Markdown in many tools and platforms, such as:
- GitHub.
- Notion.
- Documentation tools.
- Blogs.
- WordPress.

> Note:
 When you write in Markdown, the text is stored in a plain text file with the extension .md or .markdown, and then it is converted to HTML format or a print-ready PDF document by using a Markdown editor.
Markdown is a simple yet powerful tool that helps you create clear, structured, and professional documentation.
