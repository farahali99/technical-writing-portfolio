# What is a Database in Notion?
A database in Notion is a tool that helps you to organize information in a structured way.

You can use databases to track your tasks, manage projects, and store different types of information in one place.

#### Contents

- Table vs database
- Database views
- Database features 
- Create a database

## Tables vs. databases 

You must know the difference between tables and databases.

 Tables: A simple layout with rows and columns like a spreadsheet.
 Databases can filter, sort, and show data in different views, like board and calendar.

> Note: 

A database can be used to manage tasks, track projects, or organize information such as contacts and notes.

## Database views

Let's explain the different views on databases:

Table: Displays information in an organized manner, in columns and rows.

Board view: Displays your data in the form of cards, similar to kanban boards.

Calendar: Displays information and data by date.

List: Displays information in a simplified list format.

## Key Features of Notion database 

- Each item you enter into your database is a Notion page.
- You can customize properties of your database by adding name, date, status, and links.
- You can visualize your database in different ways, like a table, a calendar, and more.
- You can view multiple sets of data in one database, such as creating a comprehensive CRM database to manage information related to contacts, companies, and transactions, all within the same database.

## How to create a new database page

- Click “new page” to add a new page to your database.
- Add properties to have more options for how to organize each page.
- Add a new view to organize your information in different ways.
- Edit your view: you can edit the name, the layout, and the properties for each view.

> Note: 

 When creating a database, you can add data from scratch, or you can add existing data from your workspace.

Notion databases are flexible tools that help users organize and manage information efficiently.
