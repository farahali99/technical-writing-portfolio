# Notion Release Notes - Version 3.0
## New Features
- New user guides have been added to help new users navigate Notion smoothly.
- New templates specifically designed for beginners have been added.
- AI assistance has been added to help users find information and complete tasks more efficiently.
## Imprivements
- Improved mobile app performance on Android and iOS.
- The page navigation has been improved for a more organized experience.
## Bug Fixes
- Fixed an issue affecting file uploads on the mobile app.
- Fixed an issue where changes were not saved while working offline.
- Fixed an issue that caused Notion to freeze when working with large databases.
## Known Issues
Some users may experience limited functionality when using the mobile app without an internet connection.
